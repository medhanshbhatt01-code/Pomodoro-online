# Pomodoro Timer

A responsive Pomodoro Timer web application built with HTML, CSS, and JavaScript. It provides a simple productivity-focused interface with multiple timer modes, music controls, streak tracking, and dark mode.

## Features

* ⏱️ **Pomodoro Timer**

  * Focus
  * Short Break
  * Long Break
* 🎵 **Music Panel**

  * Integrated music controls for listening while working
* 🔥 **Streak Counter**

  * Tracks the user's current productivity streak
* 🌙 **Dark Mode**

  * Switch between light and dark themes

* ✨ **Interactive UI**

  * Animated and responsive controls

## Timer Modes

The timer contains three modes:

| Mode            | Purpose                                              |
| --------------- | ---------------------------------------------------- |
| **Focus**       | Main work session                                    |
| **Short Break** | Short rest between focus sessions                    |
| **Long Break**  | Longer rest after completing multiple focus sessions |

## Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling, responsive layouts, animations, and themes
* **JavaScript** — Timer functionality, mode switching, streak counter, music controls, mini player, and UI interactions
